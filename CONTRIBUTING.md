# Contributing to LLMCloak

Thank you for your interest in contributing.

## License

All contributions are made under the **Apache License 2.0** (inbound = outbound).
By submitting a contribution (pull request, patch, issue with proposed code), you agree that your contribution is licensed to the project under Apache 2.0.

## Developer Certificate of Origin (DCO)

To accept contributions cleanly, we use the DCO sign-off:

    git commit -s

Every commit must include a `Signed-off-by:` line, certifying that you wrote the contribution or have the right to submit it under Apache 2.0.

## Ground rules

1. **No secrets** — never commit credentials, tokens, or real passwords (CI scans for this).
2. **English only** — all code, comments, UI strings, tests, and docs in English.
3. **Tests required** — any behavioral change must come with passing tests (`pytest`).
4. **Keep dependencies clean** — new dependencies must carry permissive licenses (MIT, BSD, Apache-2.0). GPLv2-only dependencies are not accepted.
5. **Copyright headers** — keep the license header at the top of source files.

## Issues

Bug reports and feature requests are welcome. Include reproduction steps and, for security-sensitive topics (this is a secrets-pseudonymization proxy), contact the maintainers privately for anything that could expose a vulnerability: info@daemongenie.com
